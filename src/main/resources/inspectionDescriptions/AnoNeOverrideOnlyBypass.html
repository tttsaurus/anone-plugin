Reports calls to overriding methods that bypass an @OverrideOnly contract declared by a super method.

A method overriding an @OverrideOnly method is not itself restricted by the annotation. However, invoking the overriding method from unrelated code may effectively bypass the original contract. 


class Base {
    @OverrideOnly
    void hook() {}
}

class Child extends Base {
    @Override
    void hook() {
        super.hook(); // OK
    }

    void run() {
        hook(); // reported
    }
}

This inspection reports suspicious bypasses only. Such calls do not directly violate the @OverrideOnly annotation on the overriding method, because that method is not annotated itself.

Calls to super from the corresponding overriding implementation are allowed.
